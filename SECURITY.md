# Security Policy

## Supported Versions

This repository is documentation-first. Security updates are applied to the current default branch.

## Reporting A Vulnerability

If you discover a security issue:

1. Do not open a public issue with exploit details.
2. Report privately to the maintainers through your standard security contact channel.
3. Include reproduction steps, impact, and suggested remediation if available.

You will receive an acknowledgment and next-step guidance as soon as possible.
